# 版心与容量预算

排版能不能「刚好两页」，取决于你**先算后写**，而不是生成完再看。

## 基础换算

| 单位 | 值 |
|---|---|
| 1 cm | 28.35 pt |
| 1 pt | 20 twips（docx 的 `w:spacing`/`w:ind` 单位） |
| 1 cm | 567 twips |
| A4 | 21 × 29.7 cm |
| 默认版心（边距 1.6 / 1.4 / 2.15 / 2.15） | **16.7 × 26.7 cm** |
| 一页可用高度 | 26.7 × 28.35 ≈ **757 pt** |

固定行距（`w:lineRule="exact"`）下，一段的高度就是「行数 × 行距 + 段前 + 段后」，
与字体无关——这是页数稳定的根本原因。

## 每行能放多少字

```
每行字数 ≈ (区块宽 cm × 28.35 − 左右内边距 pt) / 字号 pt
```

例：16.7cm 宽的卡片，左右内边距各 15pt，正文 9pt：
`(16.7 × 28.35 − 30) / 9 ≈ 49` 字/行。

中文每字宽度 = 字号；英文/数字约 0.5–0.6 倍字号。估算取保守值即可。

边注栏 4.7cm（左缩进 0.5、右 0.15）正文宽约 4.05cm：7.5pt ≈ 15 字/行，8.5pt ≈ 13 字/行。
窄栏里先算字数，再决定字号；断词处理见 `pitfalls.md` #13。

## 常用字号与行距（本技能示例的实际取值）

| 用途 | 字号 | 固定行距 |
|---|---|---|
| 主标题 | 38 | 50 |
| 副标题 / 导语 | 12.5 | 20 |
| 板块大数字 | 24 | 27 |
| 板块标题 | 13 | 19 |
| 条目标题 | 10.5 | 15.5 |
| 条目说明 | 9 | 14.5 |
| 卡内正文 | 9–9.5 | 15–16.5 |
| 卡内标题 | 14 | 28 |
| 时间轴标签 | 10 | 15 |
| 收尾金句 | 15.5 | 27 |
| 页脚 | 7.5 | 11 |
| 边注标签 / 正文 | 7 / 7.5 | 12.5 / 13.5 |

一般规律：**行距 ≈ 字号 × 1.5~1.8**；标题行距 ≈ 字号 × 1.3。

## 一页的预算表（示例文档第 1 页）

| 元素 | 估算高度 |
|---|---|
| kicker 8pt + after 7 | ~18pt |
| 大标题 38pt | ~50pt + 4 |
| 导语 1 行 | ~20 + 10 |
| 装饰线 | ~2 + 14 |
| 导语段 2 行 | ~37 + 11 |
| 原理卡（2 行标题 + 4 行正文 + 内边距 23） | ~135pt |
| 空行 gap 16 | 16 |
| 板块头 ×3（27 + 线 + 间距） | ~36 × 3 |
| 条目 ×9（15.5+1.5 与 14.5+7） | ~38.5 × 9 |
| 板块间 gap ×2 | 7 × 2 |

合计 ≈ 720pt，落在 757 以内 → 一页刚好装下三个板块。

## 分页策略

1. **手工分页**：用 `d.pagebreak()`，不要指望自然流分页——Word 与预览器的分页点会不同。
2. 每页写完单独核算：把上面的表照着列一遍，超过 757pt 就删一行说明或缩小 gap。
3. 分页后第二页顶部用 `gap()` 把内容往下压一点，避免贴着页眉显得局促。
4. 尾页底部允许留 3–5cm 空白；比中间空一块更自然。
5. 正文页排到 757pt 以内还不够，页底再留 1.5–2cm（42–57pt）机动量：
   Word 的中文换行可能比预览多一两行，没有这点余量，最后一行会把表格行顶到下一页。

## 版心检查

所有表格宽度之和 ≤ 16.7cm。`PrintDoc.table()` 会直接抛 `ValueError`，
不要绕过它——超宽表格在 Word 里会挤出页面或被自动缩放，两种都难看。
